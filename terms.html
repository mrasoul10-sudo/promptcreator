سرویس

Prompt Creator ابزاری رایگان برای بازنویسی و ترجمه ایده‌ها به پرامپت‌های حرفه‌ای است. برنامه به همان شکلی که هست ارائه می‌شود و تضمینی برای درستی، کامل بودن یا در دسترس بودن همیشگی آن وجود ندارد.

کلید API و هزینه‌ها

ساخت پرامپت با کلید API خود شما از Anthropic انجام می‌شود. مسئولیت نگهداری کلید و هزینه‌های مصرف آن با خود شماست. استفاده از Claude تابع سیاست استفاده مجاز Anthropic است.

محتوا

مالکیت متن‌ها و پرامپت‌هایی که می‌سازید با خود شماست. از برنامه برای تولید محتوای غیرقانونی یا آسیب‌زا استفاده نکنید.

داده‌ها

همه داده‌ها فقط در مرورگر شما ذخیره می‌شوند و مسئولیت پشتیبان‌گیری از آن‌ها با شماست. جزئیات در سیاست حریم خصوصی آمده است.
