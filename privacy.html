سیاست حریم خصوصی Prompt Creator

Privacy Policy · آخرین به‌روزرسانی: مهر ۱۴۰۵ (September 2026)

چه اطلاعاتی نگه داشته می‌شود

Prompt Creator سرور یا پایگاه داده‌ای ندارد. حساب کاربری (نام، ایمیل، آواتار، رمز عبور به‌صورت هش‌شده)، تنظیمات، کلید API و همه پرامپت‌ها فقط در حافظه مرورگر خود شما (IndexedDB) ذخیره می‌شوند و برای ما یا هیچ سرور دیگری فرستاده نمی‌شوند.

ورود با گوگل

اگر با گوگل وارد شوید، گوگل نام، ایمیل و تصویر پروفایل شما را به همین صفحه در مرورگرتان می‌دهد. این اطلاعات فقط برای ساخت حساب محلی در همان مرورگر استفاده می‌شود و جای دیگری ذخیره یا ارسال نمی‌شود. فقط دسترسی‌های پایه (openid، email، profile) درخواست می‌شود.

ساخت پرامپت

متنی که برای ساخت پرامپت می‌فرستید، با کلید API خود شما مستقیماً از مرورگرتان به سرویس Claude شرکت Anthropic (api.anthropic.com) فرستاده می‌شود و تابع سیاست حریم خصوصی Anthropic است.

حذف اطلاعات

از صفحه «حساب کاربری» با «حذف حساب» می‌توانید همه اطلاعات را پاک کنید. پاک کردن داده‌های سایت در مرورگر هم همه چیز را حذف می‌کند.

English summary

Prompt Creator has no backend. Your account, settings, API key and prompts are stored only in your own browser. Google Sign-In (openid, email, profile) is used only to create a local account in your browser. Prompt text is sent directly from your browser to Anthropic's Claude API using your own API key. Delete your account in the app, or clear site data, to remove everything.
