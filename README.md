# Prompt Creator · سازنده پرامپت حرفه‌ای

ایده‌ی خامتان را به **فارسی یا انگلیسی** بنویسید؛ Prompt Creator آن را با ادبیات و ساختاری که مدل‌های هوش مصنوعی بهتر می‌فهمند بازنویسی می‌کند و یک **پرامپت حرفه‌ای به انگلیسی، فارسی یا هر دو** تحویل می‌دهد.

**آدرس اجرا:** https://mrasoul10-sudo.github.io/promptcreator/ (پس از فعال‌سازی GitHub Pages، طبق [راهنمای راه‌اندازی](docs/DEPLOYMENT.md))

## امکانات

- **بازنویسی و ترجمه هوشمند**: فارسی ⇄ انگلیسی، با نسخه‌های معادل در هر دو زبان
- **۸ نوع پرامپت**: عمومی، برنامه‌نویسی، تصویر، ویدیو، نویسندگی، تحقیق، بازاریابی، ایجنت/System Prompt
- **۳ سطح جزئیات**: خلاصه، متعادل، جامع
- **تاریخچه خودکار**: همه پرامپت‌ها ذخیره و بر اساس روز دسته‌بندی می‌شوند
- **آرشیو پیشرفته**: عنوان، پوشه، برچسب، یادداشت، علاقه‌مندی؛ جستجوی چندکلمه‌ای با پشتیبانی درست از حروف فارسی و عربی؛ فیلتر بر اساس پوشه، برچسب، نوع، زبان و تاریخ؛ مرتب‌سازی
- **صفحه اصلی آزاد**: بدون ورود می‌نویسید و ورود فقط هنگام ساخت یا ذخیره خواسته می‌شود
- **حساب کاربری ساده**: ورود با گوگل یا ایمیل، مرا به خاطر بسپار، بازیابی رمز با کد بازیابی، آواتار، تغییر رمز، حذف حساب
- **پشتیبان‌گیری**: خروجی و بازگردانی JSON برای انتقال به دستگاه دیگر
- **رابط کاربری حرفه‌ای**: راست‌به‌چپ، تم روشن و تیره، واکنش‌گرا برای موبایل، انیمیشن‌های روان، تاریخ شمسی

## نحوه کار

- سایت استاتیک است و روی **GitHub Pages** اجرا می‌شود. سرور و دیتابیس لازم ندارد.
- داده‌ها (حساب، تاریخچه، آرشیو) در **IndexedDB مرورگر** شما ذخیره می‌شوند.
- ساخت پرامپت به‌طور پیش‌فرض **رایگان** است: یک سرور کوچک روی Cloudflare (پوشه `worker/`) با کلید Gemini صاحب سایت کار می‌کند و کاربران هیچ کلیدی لازم ندارند (با سقف روزانه برای هر کاربر).
- هر کاربر می‌تواند در تنظیمات **Claude با کلید شخصی** را انتخاب کند؛ در این حالت درخواست مستقیم از مرورگر به `api.anthropic.com` می‌رود.

## شروع سریع

1. GitHub Pages را فعال کنید: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)
2. آدرس سایت را باز کنید و ثبت‌نام کنید.
3. سرویس رایگان را یک بار راه‌اندازی کنید (کلید Gemini و حساب Cloudflare): [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md#سرویس-رایگان-ساخت-پرامپت-gemini-روی-cloudflare)
4. در **استودیو** پرامپت بسازید.

## توسعه

```bash
python3 -m http.server 8765      # اجرای محلی: http://localhost:8765/
npm install                      # فقط ابزارهای توسعه
npm run test:e2e                 # تست کامل در Chromium با API شبیه‌سازی‌شده
npm run test:worker              # تست سرور رایگان (worker/)
npm run build:vendor             # بازسازی باندل SDK در assets/vendor
```

ساختار پروژه:

```
index.html            پوسته برنامه
assets/css/app.css    سیستم طراحی و استایل‌ها
assets/js/            ماژول‌ها: app, engine, prompts, auth, db, ui
assets/vendor/        SDK رسمی Anthropic (باندل‌شده)
docs/                 مستندات
tests/e2e.mjs         تست end-to-end
tools/                اسکریپت ساخت باندل SDK
```
